## Dataset

This project uses the **CEDAR Handwritten Signature Dataset**, obtained from Kaggle.

- **Dataset Name:** CEDAR-Dataset
- **Source:** Kaggle
- **Dataset Creator:** ShreelakshmiGPrakash
- **Total Images:** 2,640
- **Genuine Signatures:** 1,320
- **Forged Signatures:** 1,320
- **Classes:** Genuine and Forged

**Dataset Download:** [CEDAR-Dataset on Kaggle](https://www.kaggle.com/datasets/shreelakshmigp/cedardataset)
