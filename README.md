# Intelligent Signature Verification and Forgery Detection System

## Project Overview
This project focuses on developing an Artificial Neural Network (ANN)-based system for handwritten signature verification and forgery detection using MATLAB.

## Dataset
- Dataset: CEDAR-Dataset
- Source: Kaggle
- Total Images: 2,640
- Genuine Signatures: 1,320
- Forged Signatures: 1,320

Dataset Link: https://www.kaggle.com/datasets/shreelakshmigp/cedardataset

## Technologies Used
- MATLAB
- Artificial Neural Network (ANN)
- Image Processing
- Feature Extraction

## Model Performance
- Testing Accuracy: 70.96%
- Precision: 80.13%
- Recall: 58.74%
- F1-Score: 67.79%
